**Configuração do DHCP em um Roteador Wireless**

Prática de configuração de DHCP em ambiente doméstico simulado no Cisco Packet Tracer.

**O que foi feito:**

- Conectei 3 PCs a um roteador wireless via cabos diretos
- Configurei os PCs para obter IP automaticamente via DHCP
- Acessei a interface web do roteador (usuário/senha admin) e alterei o IP padrão do gateway para 192.168.5.1
- Ajustei o range do DHCP: início em 192.168.5.126 e máximo de 75 usuários
- Reativei o DHCP nos 3 PCs para receberem os novos endereços
- Testei conectividade com ping entre o roteador e os PCs, todos com sucesso

**Resultado:** atividade concluída com 9/9 de pontuação.

**Aprendizado:** reforça como configurar e personalizar um servidor DHCP em um roteador doméstico, controlando faixa de endereços e limite de usuários da rede.
